# PMG — média geral demonstrativa

A PMG é a soma das médias finais registradas nas tentativas encerradas dividida pela quantidade dessas tentativas. Sem pesos por créditos ou horas. Inclui reprovações, notas zero e cada repetição encerrada. Exclui tentativas em curso e médias pendentes. Se não houver médias válidas, a PMG é indisponível, não zero. A média de todas as provas AV1/AV2/AV3 não é a PMG.

## Evolução por período

A média por semestre usa a mesma regra, restrita às tentativas encerradas daquele período. Comparar somente semestres com notas válidas. Os números são calculados no backend Python. Os valores de exibição são arredondados para duas casas. A PMG é do protótipo com dados fictícios.
